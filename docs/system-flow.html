①pipeline.py
RetailSentimentPipeline._ingest()
Checks config.ingestion.fetcher_provider:
praw → _ingest_praw() → fetcher.fetch_posts(reddit, subs, cursor) + comments.fetch_comments()
arctic_shift → _ingest_arctic_shift() → arctic_shift.fetch_posts_arctic(sub, since, until)
Uses CursorTracker to track last fetch position per subreddit.
External: Reddit API Arctic Shift API
▼
②preprocess.py
preprocess_units(raw_units, english_only=True)
For each unit: detect language → skip non-English → strip HTML → normalize whitespace → check dedup cache (seen IDs set).
Returns clean_units[] — reduced set, all English, no duplicates.
Writes: raw_posts (upsert_batch)
▼
③vision.py
_enrich_with_vision(units)
For each unit with image_url:
image_preprocess.download(url) → image_preprocess.resize(img) → vision_client.caption(img_bytes)
Sets unit['image_caption']. Mutates in-place. Makes image-only posts analyzable by text LLM.
External: LLM Vision API
▼
④scorer.py
TrustScorer.score_batch(units) → score(unit)
Three-signal formula per post:
0.4 × score_metadata(unit) ← heuristics.py: account age, karma, post frequency, mod flags
0.3 × score_originality(unit) ← dedup.py: cosine hash similarity vs seen posts
0.3 × llm.check_credibility(text) ← only when 0.3 < meta < 0.8 (borderline posts only)
is_trusted = combined_score ≥ config.threshold (default 0.5). Low-trust posts are flagged not dropped.
Writes: raw_posts (trust_score, is_trusted, trust_flags)   External: LLM API (conditional)
▼
⑤analyzer.py
SentimentAnalyzer.analyze_batch(scored_units)
_get_text(unit) — builds prompt string: title + body + [image: caption]
llm.analyze_batch(texts) — sends all to LLM with prompts.py SENTIMENT_PROMPT
_build_analysis_record(unit, result) — constructs record:
  sentiment: positive / negative / neutral
  sentiment_score: 0.0 – 1.0   confidence: 0.0 – 1.0
  aspects: [pricing, quality, delivery, app_experience, …]
  aspect_scores: {aspect → score}
Writes: analyses   External: LLM API
▼
↪dispatcher.py
_maybe_create_lifecycle(analyses, scored_units)
For each high-impact negative analysis:
INSERT into post_lifecycle with state='new'
dispatch_negative_post(post, analysis) → dispatcher.py
  → email.send() via SMTP   OR   slack.send() via webhook
Writes: post_lifecycle   External: Slack Webhook SMTP Email
▼
⑥aggregator.py
Aggregator.aggregate_window('daily')
_fetch_analyses_in_window(start, end) → SELECT * FROM analyses WHERE date range
_compute_aggregate(analyses, window_key) → computes:
  total_posts, positive_rate, negative_rate, neutral_rate
  top_aspects (by frequency), net_sentiment_score
storage.upsert('aggregates', aggregate)
Reads: analyses   Writes: aggregates
▼
⑦engine.py
AlertEngine.detect_all()
Loads rules from data/alert_rules.json (user-editable thresholds)
detect_volume_spike(σ=2.0) — fetch last 30 days counts → compute μ+σ → spike if today > μ+σ×std
detect_sentiment_crash(Δ=0.3) — compare today vs 7-day avg negative rate
detect_emerging_topics() — compare aspect frequencies vs baseline period
storage.upsert('alerts', alert) → broadcast_alert() via WebSocket to AlertFeed.tsx
Reads: analyses aggregates   Writes: alerts   → WebSocket push
